#### VIEW 3: INBOX & REAL-TIME CHAT
- Path: `/chat/:chatId` and `/inbox`
- Features:
  1. Real-Time Sync: Connect chat messages to Firestore using an `onSnapshot` listener for instant real-time message feeds.

  3. The 20-Message Daily Boundary: Check the user's `dailyMessageCount`. If the count is >= 20, completely disable the message textarea and display a prompt indicating "Daily conversation energy spent. Resets at midnight."   6. Moderation / Report Engine: Place a clear "🚨 Report Account" flag element inside the header navigation. Triggering this opens an overlay modal allowing reasons selection.
